## ۲) تصمیمِ ساختاری — رضایتِ تفکیک‌شدهٔ ۵-بخشی

رضایتِ حلقه **چند-بخشی و مستقلاً قابلِ‌انتخاب/لغو** است (C-13): بلوکِ **پایه** (پردازش، الزامیِ استفاده از سرویس) + سه بلوکِ **اختیاریِ مستقل** (پیامک · اپِ بیمار · استفادهٔ ثانویه) + قواعدِ **صغار/سرپرست**. مدلِ **کنترلر (کلینیک) / پردازشگر (حلقه)** در متن روشن است.

**تکیه‌گاه‌های رویه‌ایِ کلیدی (نمونه‌های متن‌خوانده):**
- رویهٔ ایران **«اجازه‌نامهٔ استفاده از اطلاعاتِ پروندهٔ بیمار» را رضایتِ مستقلِ شناخته‌شده در پذیرش** می‌داند (healthlaw ✅) — پایهٔ بلوکِ پردازشِ ما.
- **دکترتو دو-نقطه‌ای opt-in پیامک** (ساختِ حساب + اعلامِ شماره) + opt-out + سرشمارهٔ نامیده (✅) — الگوی بلوکِ پیامک.
- **استنادِ نگهداریِ ۶ماهه به «مادهٔ ۵ آیین‌نامهٔ ادلهٔ الکترونیکی»** (دکترتو ✅) — پاسخِ نامعلومِ نگهداریِ L1a #۱۴ (ولی پروندهٔ پزشکی مبنای دیگر ~۱۰ سال دارد).
- **آیین‌نامهٔ کمیتهٔ ملیِ اخلاق ب۱۸/۲۵** (رضایتِ صریح برای استفادهٔ مجدد + انتشارِ ناشناس) — پایهٔ بلوکِ استفادهٔ ثانویه.
- **صغار: نصابِ ۱۸ سالِ شمسی + رضایتِ دوگانهٔ سرپرست/نوجوان** (م.۱۵۸ ق.م.ا + نظام‌پزشکی + آیین‌نامه ب۲۱–۲۴).

نگاشتِ بخش→عنصر→مبنا و زبانِ کاملِ هر بلوک در [`drafts/consent_patient_fa.md`](drafts/consent_patient_fa.md) آمده است.

## ۳) نگاشتِ ریسک (به L1)
پوششِ **R-2 (رضایتِ ناکافی — کیفری، احتمالِ بالا)** و بخشی از **R-5/R-6 (رضایتِ پیامک)** و **R-1 (محرمانگی)**. رضایتِ صریحِ مبتنی بر ۵۸/۵۹ = سپرِ اصلیِ کیفری.

## ۴) نامعلوم‌های وکیل‌خواه (از L3)
1. **حذف ↔ نگهداریِ اجباری:** زبانِ حذف باید مقید شود؛ استنادِ دقیقِ مدتِ نگهداریِ PHI (۶ ماهِ ادلهٔ الکترونیکی؟ ~۱۰ سالِ پروندهٔ پزشکی؟) قطعی نیست.
2. **قوّتِ ناشناس‌سازی:** آیا دادهٔ «ناشناس‌شدهٔ» حلقه از شمولِ دادهٔ سلامتِ م.۵۸ خارج می‌شود؟ (فنی+حقوقی)
3. **نصابِ سنی:** تعارضِ نظریهٔ وزارت بهداشت (بلوغ) با نظام پزشکی (۱۸ سالِ شمسی) — توصیهٔ محافظه‌کارانه: ۱۸.
4. **رضایتِ تفکیکی (C-13):** الزامِ صریحِ قانونی ندارد؛ اصلِ استنتاجیِ درست.
5. **کفایتِ رضایتِ الکترونیک** به‌عنوانِ «افرادِ مجاز» بند۴-۳ منشور.
