## وضعیتِ پیاده‌سازی (کد)
- **`../platform/`** — اسکلتِ **Django + django-ninja + PostgreSQL** (مقصدِ Evolve-not-Rewrite). نسخهٔ **v0.9 (دموپذیر)**: **هر ۸ ماژولِ DATA_MODEL §2** (≈۴۰ مدل)، **RLS**، API با **login + روترهای گاردشده**، **ETLِ کامل** (بیماران+vitals/meds/conditions/flags/followups) + **ETLِ کاتالوگ** (۵۷ قاعدهٔ ADA)، **موتورِ قاعده** با decision supportِ زنده، **frontendِ وب** با سه گردشِ کارِ مزمن (**Snapshot** + **پیشنهادهای ADA** +ack→SuggestionLog + **کارتابلِ Recall**) و **گردشِ کارِ نسخهٔ الکترونیک** (Epic 1، پلِ WebView). **یادآورِ پیامکی (Epic 6، مدیانا+NullProvider)** که حلقهٔ Recall را می‌بندد. **ایزولاسیونِ RLS روی Postgresِ واقعی اثبات شد** (`verify_rls`)؛ **بنیانِ استقرارِ Docker + CIِ GitLab** آماده شد. همگی e2e تأیید شدند؛ اپ‌های Flaskِ کارا دست‌نخورده. راهنما: [`../platform/README.md`](../platform/README.md). مبنا: [`DATA_MODEL.md`](DATA_MODEL.md).
