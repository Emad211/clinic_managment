# Clinical Rule Research

این مسیر قرارداد حاکم پژوهش و بازسازی کتابخانهٔ قواعد بالینی مطب تخصصی است.

## قواعد غیرقابل‌تغییر

- تمام Ruleهای قدیمی از نظر بالینی بی‌اعتبارند و هیچ‌کدام grandfather نمی‌شوند.
- کتابخانهٔ جدید از صفر ساخته می‌شود.
- گایدلاین‌های بین‌المللی درجه‌یک منابع اصلی‌اند.
- منابع ایرانی فقط برای زمینه و امکان اجرا بررسی می‌شوند.
- هیچ توصیه‌ای بدون متن کامل، locator، مقاله‌به‌مقاله، Risk of Bias، تعارض، computability، licensing و review عبور نمی‌کند.
- تعارض حل‌نشده برابر HOLD است.
- هیچ اقدام دارویی، تشخیصی، ارجاع یا پیام درمانی خودکار مجاز نیست.
