راه‌اندازی درست
  1. روی کامپیوتر سرور، ابتدا حسابداری را روی پورت 8080 اجرا کنید.
  2. سپس Specialist را روی پورت 8090 اجرا کنید.
  3. همهٔ کامپیوترها باید به همان مودم، Wi-Fi یا سوئیچ LAN متصل باشند.
  4. روی کلاینت‌ها چیزی نصب نکنید؛ فقط URLهای بالا را در مرورگر باز کنید.
  5. برای کامپیوتر سرور در مودم DHCP Reservation یا IP ثابت تعریف کنید تا آدرس عوض نشود.
فایل‌های clinic_new.db و specialist.db باید فقط روی سرور بمانند. بازکردن مستقیم SQLite از چند کامپیوتر یا Share کردن فایل دیتابیس، معماری این پروژه نیست.

قانون‌ها فقط برای پروفایل شبکهٔ Private ساخته می‌شوند. شبکهٔ درمانگاه را در Windows روی Private قرار دهید؛ پورت‌ها را روی اینترنت یا روتر Port Forward نکنید.
چک‌لیست قبل از استفادهٔ واقعی
✓ رمز پیش‌فرض admin/admin را تغییر دهید.
✓ یک SECRET_KEY قوی و ثابت تنظیم کنید.
✓ فقط شبکهٔ داخلیِ قابل‌اعتماد اجازهٔ دسترسی داشته باشد.
✓ از هر دو دیتابیس روی خود سرور بکاپ منظم بگیرید.
✓ روی کلاینت‌ها فقط Bookmark بسازید؛ دیتابیس کپی نشود.
✓ IP سرور را ثابت/رزرو کنید.
